# SAKURAFANG — Site web

## Fichiers
- `index.html` : page principale du site.
- `assets/sakurafang-logo.png` : logo SakuraFang utilisé dans la navigation et dans la bannière d’accueil.

## Identité visuelle
Palette violet sombre et clair, associée à du rose foncé et clair.

## Publication sur GitHub Pages
1. Décompressez l’archive.
2. Ajoutez `index.html`, `README.txt` et le dossier `assets` à la racine de votre dépôt GitHub.
3. Remplacez les anciens fichiers si nécessaire.
4. Cliquez sur **Commit changes**.
5. Attendez le déploiement GitHub Pages puis actualisez le site.

Le site comprend les divisions Valorant, Rocket League et Overwatch. Dofus et Clash of Clans ne sont pas inclus.
